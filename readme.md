# Baby Repo

This repository is dedicated to scripts, shortcuts, and other tools I've developed to streamline tasks while caring for my newborn. The primary goal is to automate routine activities, allowing for more quality time with my child.

## Tools and Platforms

The following platforms and tools are utilized in this project:

### [Baby Buddy](https://github.com/babybuddy/babybuddy)

A 👶 buddy to help caregivers track sleep, feedings, diaper changes, tummy time and more to learn about and predict baby's needs without (as much) guess work.
### [Home Assistant](https://github.com/home-assistant)

🏡 Open source home automation that puts local control and privacy first.
### [Scriptable](https://scriptable.app/)
An iOS app that enables automation using JavaScript, allowing for the creation of customizable widgets and scripts.

## Project Overview

This project encompasses various scripts and configurations aimed at simplifying daily childcare tasks:

- **Automation Scripts**: Leveraging Home Assistant to automate household tasks such as feeding schedules, sleep monitoring, and environmental adjustments (e.g., lighting, temperature).

- **Tracking Tools**: Utilizing Baby Buddy to log and monitor activities like diaper changes, feedings, and growth metrics.

- **Custom Widgets**: Developing personalized widgets with Scriptable to provide quick access to essential information and controls on iOS devices.!
